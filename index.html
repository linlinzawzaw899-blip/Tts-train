ဗီဒီယိုကို တင်လိုက်ရုံနဲ့ Gemini (သို့) AssemblyAI က အသံကို နားထောင်ပြီး စာသားထုတ်ပေးပါလိမ့်မယ်။ သင့် API key ကို ဒီစက်ထဲမှာပဲ ထားသိမ်းပြီး ရွေးထားတဲ့ ဝန်ဆောင်မှုဆီကိုပဲ တိုက်ရိုက်ပို့မှာဖြစ်လို့ ဘယ်ဆာဗာကိုမှ ကူးပို့မှာ မဟုတ်ပါဘူး။

Key မရှိသေးရင် AssemblyAI Dashboard မှာ အခမဲ့ ရယူနိုင်ပါတယ်။ ဗီဒီယိုအရွယ်အစားကြီးရင်လည်း သုံးလို့ရပါတယ် (20MB ကန့်သတ်ချက် မရှိပါ)။
